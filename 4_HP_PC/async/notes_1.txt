============What is Async?===========
- Allows your program to:
	> Do multiple tasks at once
	> Useful for:- APIs, File I/O, Databases
- Uses:
	> async--> define coroutine
	> await--> Pause execution until result is ready
**************Basic Example*************************
#!/usr/bin/python3
import asyncio

async def say_hello():
    print("Hello...")
    #pause execution until result is ready
    await asyncio.sleep(2)
    print("WOrld")

asyncio.run(say_hello())
****************************************************


==========Sequential Vs Async==========
- Sequential or synchronous programs stops execution when runing a log task
- Asynchronous program allows us to run multiple tasks at once without waiting
for one to finish.
- Program can handle multiple tasks efficiently---> reduces necessary waiting

=====When to use Asyncio=======
1. Useful for tasks with alot of wait times e.g network requests and reading
files.---> concurrent without using CPU

===The Event Loop===
- Is the core that manages and distributes tasks
