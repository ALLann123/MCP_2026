=========WHat is Logging?==========
- Provides a way to:
	> Track what your program is doing
	> Debug errors
	> Monitor applications in production
N/B: Instead of `print` we use the built-in logging module

======Logging  levels=========
DEBUG: Detailed info for developers
INFO: General events
WARNING: Something unexpected
ERROR: Something failed
CRITICAL: Serious failure


====3. Basic  Logging Example========
The code:
#!/usr/bin/python3
import logging

#detailed info to developers
logging.basicConfig(level=logging.DEBUG)


logging.debug("Debug Message")

#General events
logging.info("Info Message")

#something unexpected
logging.warning("Warning message")

#something failed
logging.error("Error Message")

#Serious failure
logging.critical("Critical Message")

Code block:
logging.basicConfig(

============5. Logging to a File=================
- We can also direct to a file the output of the logs
*********************************************************
#!/usr/bin/python3
import logging

logging.basicConfig(
    filename="app.log",
    level=logging.INFO,
    format="%(asctime)s - %(levelname)s - %(message)s"
)

logging.debug("Debug message")
logging.info("Info message")
logging.warning("Warning message")
logging.error("Error Message")

Learn:
	> Logging levels
	> Error Handling
	> Writing logs to file

#!/usr/bin/python3
import logging

logging.basicConfig(
    filename="calculator.log",
    level=logging.INFO,
    format="%(asctime)s - %(levelname)s - %(message)s",  
)


def add(a, b):
    logging.info(f"Adding {a} + {b}")
    return a+b

def divide(a, b):
    try:
        result=a/b
        logging.info(f"Dividing {a}/{b}")
        return result
    except ZeroDivisionError:
        logging.error("Attempted Division by zero", exc_info=True)
        return None
    
def main():
    logging.info("Calculator started")

    print("1. Add\n 2.Divide")
    choice=input("Choose option: ")

    a=float(input("Enter first number: "))
    b=float(input("Enter Second number:"))

    if choice == "1":
        print("Result: ", add(a,b))
    elif choice=="2":
        print("Result: ", divide(a,b))
    else:
        logging.warning("Invalid choice entered")

if __name__=="__main__":
    main()
